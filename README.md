Input/Output Contract

Input:
    Please enter a positive, whole-number temperature value: 80
    Is the temperature in C or F?: F

Output:
    Temperature in C: 26

Test scenarios:
    Test 1: 0 C converts to 32 F
    Test 2: 32 F converts to 0 C
    Test 3: An unsupported direction produces an error "Invalid input. Conversion not possible."
    Test 4: If a negative temperature is inputted, output "Invalid input. Input must be positive and a whole number."
